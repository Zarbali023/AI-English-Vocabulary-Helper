# AI English Vocabulary Helper

## Purpose

This project is a learning aid for English learners. It explains unfamiliar
words and gives learners a short opportunity to practise using them.

## First useful version

The first version will accept one English word and provide:

- a plain-language definition
- pronunciation help
- the part of speech
- one example sentence
- related words
- a short practice question

The tool is intended to support learning, not replace a dictionary or teacher.

## Try the browser app

Open `index.html` in a web browser. Enter one of the AI vocabulary terms to
see its explanation, example, and practice question.

## How it will be checked

- Test common words, difficult words, and a misspelled word.
- Compare definitions with a reliable dictionary.
- Check that each example sentence uses the word correctly.
- Check that each quiz question has a clear answer.
- Ask another learner to try the tool and give feedback.

## Sources and safeguards

AI-generated definitions and examples must be checked for accuracy. Words with
multiple meanings should include the relevant context. The project should not
collect unnecessary personal information.
